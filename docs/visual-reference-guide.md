# Black Sigil — Visual Reference Guide

Last updated: October 26, 2026  
Status: Working art and atmosphere direction  
Primary reference lens: Dark Souls III  
Rule: Use references for feel, proportion, timing, and atmosphere. Do not copy protected characters, names, creatures, maps, UI, or assets.

---

## 1. Purpose

This document tells collaborators and Claude how to use visual/video references for Black Sigil.

We are not recreating Dark Souls III.  
We are extracting useful design language:

- silhouette clarity
- weight and proportion
- cold atmosphere
- readable combat motion
- ruined medieval architecture
- restrained color

All final work must remain original to Black Sigil.

---

## 2. How to Use References

When images or videos are added to this library:

1. Study the reference
2. Extract the useful principle
3. Apply that principle to Black Sigil’s original world, armor, enemies, and UI
4. Avoid one-to-one recreation

For every major reference batch, note:
- What stands out
- What should be reused
- What should be avoided
